# ADR 0002: 백엔드 스택: NestJS (TypeScript)

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

백엔드 실무 경험이 없는 프론트엔드 엔지니어가 서버를 A-Z로 학습한다. Kotlin + Spring Boot(국내 이커머스 표준)와 NestJS를 비교했다.

## 결정

NestJS로 한다. 도메인별 모듈의 모듈러 모놀리스로 구성하고, 모듈 간 의존은 공개 인터페이스와 이벤트로만 한다.

## 결과

- 언어를 바꾸지 않고 백엔드 개념(트랜잭션, 동시성, 이벤트)에 집중할 수 있다
- 대가: 국내 이커머스 백엔드 표준(Spring/JPA)과 거리가 있다. 스펙 우선 도구 생태계가 Spring보다 덜 성숙하다(ADR 0003)

## 검토한 대안

- Kotlin + Spring Boot: 스펙 우선 도구가 성숙하고 채용 시장과 맞지만 언어·생태계 학습이 동시에 필요하다

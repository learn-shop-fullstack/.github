# ADR 0005: ORM: Drizzle ORM + drizzle-kit

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

필터→SQL 변환, 행 락, `EXPLAIN` 등 SQL을 직접 다루는 것이 학습 목표다.

## 결정

Drizzle을 쓴다. 마이그레이션은 `drizzle-kit generate`로 SQL 파일을 생성해 리뷰·커밋하고 적용한다. `push`는 로컬 실험에만 쓴다. Nest 공식 모듈이 없으므로 커넥션 풀을 커스텀 프로바이더로 주입한다.

## 결과

- 쿼리가 SQL과 거의 1:1이고 `for('update', { skipLocked: true })` 같은 행 락을 지원한다
- 생성된 SQL 마이그레이션을 직접 리뷰하며 DDL을 배운다
- 대가: Nest 통합을 직접 구성해야 한다

## 검토한 대안

- Kysely: 더 순수한 쿼리 빌더지만 스키마 정의·마이그레이션 생성이 약하다
- Prisma, TypeORM: 추상화가 커서 SQL 학습 목표와 거리가 있다

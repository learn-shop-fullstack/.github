# ADR 0007: 서비스 형태: 멀티 판매자 마켓플레이스, 한 계정이 구매자 겸 판매자

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

참고 프로젝트(CatdogEats)의 기능 대부분이 판매자 화면을 전제한다.

## 결정

구매자 / 판매자 / 플랫폼 운영자 3역할의 마켓플레이스로 한다. 일반 계정은 모두 구매자이고, 판매자는 같은 계정에 판매자 프로필을 붙인다(1계정 1스토어). 운영자 계정은 분리한다. 권한은 역할 문자열이 아니라 "구매/판매 컨텍스트 + 리소스 소유자"로 판단한다. 자기 스토어 상품의 구매·리뷰·쿠폰 사용은 막는다. 주문은 결제 1건 → 판매자별 주문 → 주문 항목으로 나눈다. 화면은 스토어 / 셀러센터 / 어드민으로 분리한다.

## 결과

- 주문 분할, 판매자별 배송비·정산, 소유권 검사 등 실무적인 도메인을 다룬다
- 대가: 도메인 모델과 화면 수가 크게 늘어난다

## 검토한 대안

- 단일 쇼핑몰: 단순하지만 정산·셀러센터·구매자↔판매자 채팅이 빠진다

# ADR 0008: LLM: 제공자 독립 계층

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

리뷰 요약에 LLM을 쓰되, 어떤 모델이든 교체할 수 있기를 원한다.

## 결정

도메인은 `LlmClient` 포트(`generateStructured`, `generateText`)만 의존한다. 어댑터: AI SDK(공식 제공자), OpenAI 호환 HTTP(Ollama·vLLM·게이트웨이), 가짜 구현(테스트). 작업 단계별 모델을 설정으로 지정하고, 호출마다 제공자·모델·프롬프트 버전·토큰·지연을 기록한다. 구조화 출력은 JSON 스키마 지원 시 사용, 아니면 JSON 모드 + 검증 + 재시도로 폴백한다.

## 결과

- 상용·로컬 모델을 같은 데이터로 비교할 수 있다
- 대가: 어댑터 유지 비용. AI SDK 7.x는 Node 22+ · ESM 전용이라 Nest(CommonJS 기본)와의 호환을 착수 시 확인해야 한다

## 검토한 대안

- 특정 제공자 SDK 직접 사용: 단순하지만 교체가 어렵다

# ADR 0009: 결제: PG 추상화 + 토스페이먼츠 테스트 모드 / 모의 PG

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

참고 프로젝트는 토스페이먼츠를 썼다. 토스 테스트 모드는 실제 결제 없이 결제 위젯·승인 흐름을 경험할 수 있지만, 서버 봇이 결제할 수 없고(위젯이 브라우저 결제창을 요구) 장애 주입·대량 트래픽이 불가능하다.

## 결정

`PaymentGateway` 포트 뒤에 토스페이먼츠 어댑터(사람의 브라우저 결제)와 모의 PG 어댑터(봇, 장애 주입)를 둔다. 모의 PG는 shop-sim-vendor에 두고 토스와 같은 요청·응답 형태를 쓴다. 봇 계정은 모의 PG로 라우팅한다.

## 결과

- 실제 PG 연동 경험과 시뮬레이션·장애 주입을 모두 얻는다. 멀티 PG는 국내 커머스의 실제 구조와도 같다
- 대가: 어댑터 2개 유지, 모의 PG가 토스 API 형태를 따라가야 한다

## 검토한 대안

- 토스만 사용: 시뮬레이터가 동작하지 않는다
- 모의 PG만 사용: 실제 PG 연동 경험이 빠진다

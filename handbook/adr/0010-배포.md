# ADR 0010: 배포: Oracle Cloud Always Free ARM, 무료 구성

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

학습용이라 비용 0원을 원한다. Kafka와 OpenSearch(둘 다 JVM)를 포함해 필요 메모리는 7~9GB로 추정된다. Hetzner는 2026년 큰 폭으로 인상됐고, AWS Lightsail 서울은 16GB가 월 $84다.

## 결정

Oracle Cloud Always Free ARM(문서상 2 OCPU / 12GB)에 docker-compose로 배포한다. compose는 역할별 파일로 나누고 주소는 환경 변수로 받아 나중에 코드 변경 없이 VM을 분리한다. 모든 이미지는 arm64로 빌드한다. 부가 서비스도 무료 구간(R2, GHCR, GitHub Actions, Sentry)을 쓴다. 부하 생성은 VM 밖(로컬 PC)에서 한다.

## 결과

- 비용 0원, 제한된 메모리 예산 안에서 운영하는 경험
- 대가: 무료 한도 정책 변경·용량 부족·유휴 회수 위험 → 플랜 B(로컬 + Cloudflare Tunnel), 모든 데이터는 재생성 가능하게

## 검토한 대안

- 유료 VM 1대(16GB): 안정적이지만 월 비용 발생
- 역할별 유료 VM 3대: 학습 효과는 크지만 비용 2~3배

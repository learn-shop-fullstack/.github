# ADR 0011: 협업 방식: Claude가 아주 작게 구현하고 내가 세밀하게 리뷰한다

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

목표 중 하나는 AI 의존으로 떨어진 코딩 감각 회복이다. 처음에는 핵심 로직을 직접 짜는 방식을 검토했지만, 백엔드·인프라는 모르는 부분이 많아 직접 짜기 어렵다.

## 결정

Claude가 개념 하나 단위(diff 50줄 이내)로 코드를 쓰고, 착수 전 설명 → 코드 → 리뷰 가이드(이해 확인 질문 포함) → 확인 방법 → 승인 순으로 진행한다. 상세는 `working-agreement.md`.

## 결과

- 모르는 영역도 진도를 내면서 한 줄씩 이해할 수 있다
- 대가: 읽으면 이해한 것 같지만 혼자 못 짜는 함정 → 이해 확인 질문에서 막히면 그 부분을 직접 다시 짠다

## 검토한 대안

- 핵심 로직 직접 작성: 손코딩 효과는 크지만 모르는 영역에서 진도가 멈춘다
